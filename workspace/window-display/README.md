# 橱窗陈列视线设计器

换季摆橱窗的预演工具：在浏览器里把橱窗切成**近景 / 中景 / 远景**三层，拖入人台、灯箱、道具，设定街对面顾客的视点高度，系统实时画出视线并用几何相交判断遮挡——被前层挡住的道具直接标成「看不全」。纯前端单页应用，零后端，方案保存在浏览器 IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 产物在 dist/，任意静态服务器即可托管
```

## 功能

- **三层侧剖面画布**：玻璃在左、后墙在右，近/中/远三条层带；横向拖动道具跨带自动换层
- **道具**：人台 / 灯箱 / 展台 / 木箱 / 绿植 / 货架，可拖拽、旋转（双击 +15°，滚轮微调，面板滑杆精调）；拖拽和旋转都做包围盒约束，**翻不出窗框**
- **顾客视点**：拖动街对面的小人或滑杆设定视点高度（0.8–2.3m）与隔街距离
- **视线遮挡**：从视点向每个道具的可见高度采样 48 条视线，与前层道具竖直区间及窗台/窗楣开口做相交判断；可见比例 <100% 的道具画红色虚线框并标「看不全 · 可见 N%」，右侧面板给出遮挡报告（被谁挡住）
- **方案管理**：命名 + 季节标签保存到 IndexedDB，可加载、删除
- **季节对比**：左右并排渲染两个已保存方案（只读），各自带视线与遮挡报告

## 目录结构

```
src/
  geometry.js   # 世界坐标、旋转包围盒、窗框约束、视线遮挡计算
  templates.js  # 道具模板与默认演示方案
  db.js         # IndexedDB 封装（plans 表）
  Stage.jsx     # Canvas 画布：渲染 + 拖拽/旋转/视点交互
  App.jsx       # 编辑 / 对比两种模式，方案管理，属性面板
```

## 默认演示场景

打开即是一个典型「翻车现场」：近景高挂灯箱压住远景主推人台的上半身，中景绿植再挡一截，人台只剩 21% 可见；木箱被窗台挡住下半截。把灯箱拖高、绿植挪开，可以看着人台的可见比例一路涨回 100%。
